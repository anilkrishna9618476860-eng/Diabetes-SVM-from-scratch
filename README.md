# Diabetes Prediction Using SVM From Scratch

## 📌 Project Overview

This project implements a **Support Vector Machine (SVM) classifier from scratch using Python** to predict diabetes based on medical attributes. It focuses on understanding the mathematical foundations of SVM, including maximum-margin classification, optimization, and decision boundary construction.

Unlike implementations that directly use prebuilt SVM models, this project emphasizes understanding and implementing the core algorithm from fundamental concepts.

## 🎯 Why Did I Choose This Project?

I chose this project to explore how machine learning can be applied to real-world healthcare challenges, particularly diabetes prediction.

Diabetes is a significant health concern, and machine learning offers an opportunity to analyze medical data and identify patterns associated with diabetes.

I also wanted to move beyond using prebuilt machine learning libraries and understand how algorithms work internally. Implementing SVM from scratch helped me strengthen my knowledge of mathematical optimization, classification, decision boundaries, and model training.
